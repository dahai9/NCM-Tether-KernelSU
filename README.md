# NCM Tether (KernelSU/Magisk Module)

Replace RNDIS with NCM for USB tethering - faster and more efficient networking.

## Description

This module attempts to switch the default USB tethering protocol from RNDIS to NCM. NCM (Network Control Model) is generally more efficient and provides better performance than the older RNDIS protocol on modern operating systems (Linux, macOS, and Windows with appropriate drivers).

## Features

- Switches USB tethering to NCM.
- Improved networking efficiency.
- Compatible with KernelSU and Magisk.

## Installation

1. Download the latest release `.zip` file from the [Releases](../../releases) page.
2. Install via KernelSU Manager or Magisk Manager.
3. Reboot your device.
